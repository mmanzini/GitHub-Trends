# GitHub Trending – 2026-07-26 (Sunday)

## Editor's Take
Two repos stand out today. **xai-org/grok-build** (22k stars in under two weeks) is xAI's official open-source coding agent harness and TUI — a direct competitor to Claude Code with a fullscreen, mouse-interactive interface built in Rust, and it signals that every major AI lab is now shipping its own coding agent CLI. Worth covering side-by-side with Claude Code for the tooling audience. **andrewyng/openworker** (6.6k stars in six days) is Andrew Ng releasing a practical reference implementation for building desktop AI agents with multi-LLM support and 25+ integrations via aisuite — it's rare to get a high-quality, opinionated, agentic architecture from someone at his level, and it's open source.
