# GitHub Trending – 2026-08-13 (Thursday)

## Editor's Take

Two things are genuinely worth stopping for today. First, **deepseek-ai/deepseek-harness** — nearly 40k stars on its first day, a plugin-first open-source agent harness from DeepSeek AI. The "everything is a plugin" philosophy here is the same bet that made VS Code dominant, and seeing a major AI lab stake a product on composable agent infrastructure is a strong signal for where the ecosystem is heading. Second, **Leutenegger/book-to-skill** is directly in Claude Code territory: it converts any technical book PDF into a ready-to-use Claude Code skill, which is a concrete workflow improvement for anyone building with Claude Code day-to-day. Also worth a look: **gvzdv/claudish-to-english**, a Claude Code plugin that uses a local LLM to rewrite Claude's dense assistant messages into plainer English — a small but telling example of the meta-tooling layer forming around Claude Code itself.
