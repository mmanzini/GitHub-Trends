# GitHub Trending – 2026-08-28 (Friday)

## Editor's Take

Two things worth your attention today. **deepseek-ai/deepseek-harness** (202K stars in under 3 weeks) is the biggest AI story on GitHub right now — it's a full agent harness built around a Cordis plugin system where literally everything, including the desktop shell, is a swappable plugin. The ecosystem has already spawned its own desktop client and curated plugin list, suggesting this is trying to be the LLM equivalent of a VS Code extension marketplace. **duty1g/x64dbg-mcp-server** is smaller but sharply on-niche: a zero-dependency MCP plugin for the x64dbg debugger, built in Zig, that lets any MCP-compatible AI (including Claude Code) set breakpoints, read memory, and step through code in a live binary. It's one of the most concrete examples to date of MCP unlocking AI control over developer tooling that was never designed for it.
