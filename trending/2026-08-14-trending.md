# GitHub Trending – 2026-08-14 (Friday)

## Editor's Take
The dominant story this week is **deepseek-ai/deepseek-harness**, which erupted to 95k stars within roughly 24 hours of being published — one of the fastest star trajectories seen on GitHub for an AI project. It's a plugin-based agent framework from DeepSeek AI built on the Cordis composability paradigm, and the surrounding ecosystem (desktop app, web UI plugins, an awesome-list) sprang up almost simultaneously, signaling serious community investment. For the 30-day window, **andrewyng/openworker** from Andrew Ng is equally worth the creator's attention: it positions itself not as a developer framework but as a local AI coworker that delivers finished work — a genuinely different framing for the "AI agent" story that will resonate with non-technical audiences.
