# GitHub Trending – 2026-08-21 (Friday)

## Editor's Take
Two repos stand out for AI agent content this week. **yetone/cumora** (2,858 stars) is building the team-chat primitive the agent-collaboration space has been missing — a cross-platform client where Claude Code and Codex act as first-class teammates with persistent context, directly illustrating what multi-agent work looks like day-to-day. **CopilotKit/OpenBot** (2,108 stars) takes the complementary view: each AI coworker gets a dedicated browser and filesystem, and every action is decided before it happens and logged after — strong material for agent governance and transparency content. The 30-day chart is dominated by **deepseek-ai/deepseek-harness** (181k stars), an official plugin-everything framework from DeepSeek that has already spawned a desktop client and a growing skills ecosystem — worth covering as a counterpart to Claude's own skill/plugin infrastructure.
