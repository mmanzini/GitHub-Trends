# GitHub Trending – 2026-08-16 (Sunday)

## Editor's Take
The story this week is almost entirely one story: DeepSeek dropped **deepseek-harness** on August 13th and it hit 130k stars in under three days, while a full ecosystem of desktop apps, plugin collections, web UIs, routing kits, and presets materialized around it within the same 72-hour window. The "everything is a plugin" architecture positions DSH as a direct competitor to Claude Code and similar agentic harnesses — the speed at which the community scaffolded an entire toolchain around it makes this essential viewing for anyone covering AI agents. Also worth a closer look: **andrewyng/openworker**, Andrew Ng's open-source AI coworker that supports MCP and 25+ integrations with bring-your-own-key model support — it's a clean example of the "finished deliverables, not just chat" pattern that's becoming a central design philosophy for agent products.
