# GitHub Trending – 2026-08-02 (Sunday)

## Editor's Take
Two repos stand out today. **andrewyng/openworker** is Andrew Ng's open-source AI desktop agent that executes real deliverables (documents, code, reports) across 25+ tool integrations using your own API keys — an ideal showcase for how agentic AI is moving from chat to genuine task completion. **yc-software/qm** (7,107 stars in just 4 days) is a multiplayer agent harness built for collaborative work, signaling that multi-agent coordination is fast becoming a product category, not just a research concept. **microsoft/skill-recorder** is also worth a second look: it records on-screen work and reconstructs it as reusable agent skills, which is a compelling angle on how future agents might learn from humans rather than just being prompted by them.
