# GitHub Trending – 2026-08-11 (Tuesday)

## Editor's Take
Two repos stand out today for AI/agent content. **andrewyng/openworker** (30-day list, 14k stars) is Andrew Ng's open-source AI coworker that delivers finished work—documents, Slack replies, calendar updates—rather than just chat; it ships with MCP support, 25+ integrations, and works with every major LLM provider including local models via Ollama, making it unusually demo-friendly. **ShawnPana/phone-harness** (weekly list, 1.5k stars in four days) is a Python library that lets any AI agent control a physical phone via code, which is a striking concrete demonstration of agentic autonomy that's likely to resonate with audiences still asking "but what can agents actually *do*?"
