# GitHub Trending – 2026-07-31 (Friday)

## Editor's Take
Two threads are worth calling out today. First, **VictorTaelin/OptMem** is a tiny but sharp idea: permanent memory for AI agents delivered as a 426-token prompt and a single script — no infrastructure, no database, plug and play. It's the kind of minimal-footprint solution that AI agent builders will share widely, and it makes excellent short-form content. Second, **0xwilliamortiz** dropped two Claude Code–adjacent repos in the same week — one that installs a YAGNI-first thinking style into your agent, and one that turns Claude Code into a multi-model CLI that runs on any provider. Taken together they represent a small but meaningful ecosystem of Claude Code customization that's worth a dedicated post. In the monthly view, **andrewyng/openworker** (Andrew Ng's open-source local AI agent with 25+ app connectors) is the biggest story if you haven't covered it yet.
