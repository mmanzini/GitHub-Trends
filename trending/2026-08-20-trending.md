# GitHub Trending – 2026-08-20 (Thursday)

## Editor's Take
The unmistakable story this week is **DeepSeek Harness** (`deepseek-ai/deepseek-harness`) — a TypeScript-first AI agent platform that launched August 13 under the philosophy "Everything is a Plugin," and already has 174K stars with an entire mini-ecosystem of plugins appearing on trending alongside it (routing suites, preset packs, a marketplace, a desktop client). For AI/agent content creators, this is a platform launch worth covering in depth: it uses a Cordis plugin architecture, has first-party MCP and agent support, and has spawned more third-party plugins in one week than most frameworks get in a year. The secondary standout is **CopilotKit/OpenBot**, which gives open-source AI agents their own dedicated compute environment — browser, files, and tools — representing the "every agent gets a computer" pattern that's been building as a trend all year.
