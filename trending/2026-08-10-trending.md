# GitHub Trending – 2026-08-10 (Monday)

## Editor's Take
Two threads dominate this week. First, agent skill ecosystems are clearly a growth market: three of the top ten weekly repos are packaged agent skills (for Claude, ChatGPT, Kimi, and Manus), signaling that curated, composable AI behaviors are becoming their own content genre worth covering. Second, **ShawnPana/phone-harness** is the most interesting infrastructure pick this week — a Python framework that lets agents control a phone, arriving at 1,300 stars in under three days, which suggests the mobile-agent frontier is heating up fast. For deeper context, this week's 30-day view tells an even bigger story: Andrew Ng's **andrewyng/openworker** (14k stars) is a fully open-source desktop AI agent with MCP support, multi-LLM flexibility, and a privacy-first architecture — the kind of reference project that shapes how the field thinks about agent design.
