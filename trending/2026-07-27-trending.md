# GitHub Trending – 2026-07-27 (Monday)

## Editor's Take
Two repos stand out hard this week. **andrewyng/openworker** is Andrew Ng's open-source desktop AI coworker—25+ app integrations, any-LLM support, local-first privacy, and an approval-gated agent loop. This is a rare combination of credibility (Ng), practical design, and direct relevance to the "agents that actually do work" story you can build an entire video around. The other is **VictorTaelin/OptMem**: a 426-token prompt that adds permanent memory to any AI agent with zero infrastructure. The simplicity is the hook—no vector DB, no embeddings, just clever prompt design. Both are immediately graspable for an audience that wants to build with agents, not just read about them.
