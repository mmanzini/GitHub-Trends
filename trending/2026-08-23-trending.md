# GitHub Trending – 2026-08-23 (Sunday)

## Editor's Take

Two repos are worth immediate attention today. **cumora** (yetone/cumora) is a cross-platform team-chat app where AI agents are fully integrated as teammates and can run Claude Code or Codex as their brains — a real-world multi-agent collaboration layer that's already pulling nearly 3k stars in under a week. **OpenBot** from CopilotKit is the other standout: it gives each AI coworker its own browser, file system, and tool access, with every action reviewed before execution and logged after — the agent-governance angle makes it content gold for anyone covering agentic autonomy vs. human oversight. Both signal that the "AI agents as team members" pattern is crystallizing into shipping products.
