# GitHub Trending – 2026-08-07 (Friday)

## Editor's Take
The standout story today isn't a single repo — it's a pattern: four of the top 10 trending repos this week are Codex agent skills (human-writing, open-kimi-ppt-skill, photo-abstract-editorial, gathered-scenes-zine-skill), all gaining thousands of stars. This is the clearest signal yet that a Codex skill ecosystem is forming, parallel to what happened with VS Code extensions years ago — worth a dedicated piece on what this means for the "AI skill economy." The second pick is **Accio-org/RealReplicaBench**, a framework for benchmarking long-horizon agents against high-fidelity replicas of real web services; as agent evaluation becomes a serious discipline, this kind of infrastructure matters, and it's still early enough that covering it now gives you a head start on the conversation.
