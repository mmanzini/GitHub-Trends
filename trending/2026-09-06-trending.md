Two repos stand out this week. `anthropics/commerce-agents` is a reference blueprint from Anthropic itself for building shopping and merchant agents with Claude across retail, telecom, and entertainment — immediately useful content for anyone covering practical Claude agent applications. `2akouwu/reverify` introduces a compelling anti-hallucination architecture: AI proposes, deterministic tools verify each claim against ground truth, with grounded facts surviving context resets via an MCP server.
