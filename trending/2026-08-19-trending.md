# GitHub Trending – 2026-08-19 (Wednesday)

## Editor's Take
The dominant story this week is **DeepSeek Harness** (`deepseek-ai/deepseek-harness`), which launched on August 13 and has already amassed 167K stars — one of the fastest-rising repos in recent GitHub history. It's an AI agent framework built around the Cordis IoC runtime where "everything is a plugin," and it immediately spawned a full ecosystem: a desktop client, a curated plugin directory, a Claude Code–styled TUI, and multiple LLM routing presets, all within 48 hours. This is a content goldmine for AI agent coverage — the architectural angle (composable plugin runtimes vs. monolithic agent frameworks) practically writes itself. Also worth watching is **cumora** (`yetone/cumora`), a cross-platform team chat that treats Claude Code and Codex as first-class AI teammates — a rare, concrete example of human-AI collab in a shared workspace rather than a solo coding session.
